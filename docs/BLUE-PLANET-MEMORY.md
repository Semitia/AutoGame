## 用户指引（长期保留）
- 目标：代理自主经营新号，积累机制与打法，快速提升战力、推进关卡、获得奖励，最终与用户大号打合作。用户指出合作模式是好装备的重要来源；具体解锁条件待实测。
- 路线：先持续推关，直到打不过；再回补此前关卡的满血通关奖励，并探索抽卡、装备、强化等养成；进入长草期后日常清体力。不要在明显卡关时无脑重复。
- 选阵容必须综合**稀有度、实际强度/战斗力、职业、技能特性、队伍配合及关卡怪物特性**。用户强调通常高稀有度角色强很多，即使等级/面板较低也应优先评估。不能为了沿用脚本配置而搁置新角色。
- 四个位置按职责配置，可2输出1控制1辅助，也可1输出3辅助、3输出1辅助；不绑定固定英雄。换阵容后同步脚本名称、buff关键词、优先级和保留数量。GUI配置以后再做。
- 战术基线：随机召唤1阶；相同英雄同阶合成，最高4阶，4阶额外选角色buff；每召唤5次扩一格；强化选buff，两种费用递增。
- 输出有空格先保留；控制/辅助通常保留1～2个，超量优先合成，多个可合成阶级时先低阶。应召唤但满格时再考虑合输出腾位。依据下一次强化费/召唤费维持约2:1，谁相对便宜选谁，不比较累计花费。
- buff先按角色优先级。原大号例：海王→剑圣→雪姬→美人鱼；后续按阵容、技能与怪物调整，不是永久固定名单。
- 执行：战斗交给脚本，局外由代理操作；单局/循环都要支持。大号后台清体力时继续练小号，偶尔检查大号，不能干等。已有可用脚本先用，不长时间重构代替实际推进。
- 用户会顺手清红点，先看实时状态避免重复。截图只在关键变化/结果不明确时看，不反复读取同屏。记录精简，未来定时启动时可快速接手；当前未创建定时任务。
