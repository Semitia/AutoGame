# MuMu 第 35 关后台脚本（原型）

> 本文是第一版的历史说明。当前启动器已切换到第 34 关策略版，请阅读 [README-v2.md](README-v2.md)。

适配本机 MuMu 安卓 15、设备 `emulator-5554`、安卓分辨率 **1080×1920**，以及当前游戏的第 35 关“龙巢探秘”。Windows 窗口大小和位置不影响坐标。Python 使用本机 Codex 自带运行时，OpenCV 已放入 `.deps`。

**当前状态：后台控制可用，战斗策略未通过验证。两局实测均失败，已停止。连续模式已禁用，不能将本版当作稳定清体力工具。**

## 使用

先把游戏留在第 35 关的选关首页，再运行：

- `Test-One.cmd`：隐藏游戏窗口，测试一局，显示日志控制台。
- `Farm.cmd`：预留连续模式入口。当前缺少实际胜利模板，会提示尚未验证并退出。
- `Start-Hidden.cmd`：预留隐藏控制台的连续模式入口，当前同样禁用。
- `Stop.cmd`：请求脚本停止，并显示游戏窗口。若正在已识别的战斗中，会尝试暂停；应查看游戏确认状态。
- `Show-Game.cmd`：只显示游戏窗口，不停止脚本。

启动后不要同时手动操作游戏。其他 Windows 应用可以正常使用，脚本不移动桌面鼠标、不要求游戏窗口获得焦点。关闭模拟器或让电脑睡眠会中断运行。

## 当前策略

1. 识别第 35 关首页，开始挑战；提示已通关时选择“继续挑战”。
2. 通过 ADB 获取安卓内部截图，本地 OpenCV 识别；不调用大模型或付费视觉 API。
3. 自动召唤；根据图像和颜色相似度尝试拖动合成，检查来源格是否空出。游戏自身决定两个单位是否满足合成条件，脚本尚未精确读取等级；未确认成功的组合暂时跳过。
4. 每约 9 秒尝试强化；三选一默认选择中间卡片。
5. 识别结算并返回。未确认胜利时停止，避免连续失败。

## 限制

- 这是固定游戏、固定关卡、固定分辨率的原型，不是通用游戏机器人。
- 当前合成范围为底部 7 格和右侧向上扩展的 2 格；战斗特效可能降低识别准确率。
- 暂未 OCR 读取剩余体力。未知界面（包含尚未采集模板的体力不足弹窗）会在连续约 8 次识别失败后停止，不会处理购买体力。
- 尚需以实际通关结果验证长期连续运行；不能仅凭一次合成或推进波数判定稳定。
- 最大运行时间到期会结束脚本，但不保证战斗已结束。

每次运行保存 `runs/时间/events.jsonl`、`latest.png`、间隔截图和结算截图，用于排查。`STOP` 文件是停止信号；下一次成功获得独占运行锁后会清除旧信号。禁止同时启动多个实例，脚本有文件锁。

## 命令行

```text
python farmer.py --hide --runs 1 --minutes 15
python farmer.py --hide --runs 20 --minutes 180
python farmer.py --hide --resume-battle --runs 1
```

迁移到其他电脑需修改 Python、ADB、MuMuManager 路径，安装 `requirements.txt` 中的依赖，并重新确认设备编号与分辨率。
