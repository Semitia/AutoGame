## 格内自相似实验（最新）

### 前排位置与遮挡补充实验

现汇总共享同一平移的多处纹理前景，记录 `pair_support`、`pair_center_y`。这是可见前景中心，**不是语义上的人物重心或脚底检测**；武器/头盔都可能贡献，单个装饰物不能作为位置基准。只找到局部重复无法证明恰好两人。

新增同屏前排布局校验：按前排间距对齐尺度，再比较覆盖不同高度的多处前景；匹配到显著向下偏移时，将二阶降为未知（`lowered_pair_possible_occluded_third`），不直接提升为三阶。样本中二/三人大小略有差异，不能只比较一个头盔框的纵坐标。尚未实现语义身体分割、后排零碎部件聚合或视频验证。

- 开发图人为遮住红发三人组后排头部：原来错报二阶，现在结合同屏二人参照返回未知，记录前排下移约0.086格距；孤立单格方法仍误报二阶。不是“已识别出被遮挡第三人”。
- 原开发图仍8组正确、四阶未知。
- **代价**：战斗图8个占用仍全检出，阶级变为7个正确、1个未知（底排右侧真二阶骑士也被保守拦截）。不同格子的姿态/尺度差异仍会干扰布局比较，不能把同格同步推广成跨格同步。此前8/8是未加布局校验版本的结果。
- 新规则仍只离线评估，不参与合成。可视化 `runtime/tier-structure-report/layout-occlusion.png` 中蓝色点为汇总的匹配前景，不能解释为精确人体轮廓。

新增 `tier_structure.py`：按用户建议，将占用判断和阶级分开。与同棋盘人工确认的空格参考做颜色差分，去除整体亮度偏移；在格内寻找有纹理的重复前景子区域，并检查两人水平、三人三角排列。不读取英雄头像库，不需要知道英雄名字。同格动作同步是用户提供的机制说明；样本中重复区域相似度多数为0.90～0.99，与此相符，但没有做视频同步验证。

从同屏二/三阶自动截取小人局部作为大小参考，尝试解释单人；没有可匹配参照时，紧凑前景只给出一阶候选。宽大前景不能直接算四阶：武器、光环、邻格伸入和遮挡都会改变轮廓。点击详情确认占用尚未接入此实验。

## 旧头像模板原型

用户规则：1/2/3阶为同格1/2/3个小人，4阶为放大单体。实现位于 `games/bilibili_hero_merge/tier_vision.py`。

当前用少量头部外观模板、多尺度/旋转匹配、去重以及单人/双人/三角排列约束。4阶使用相对格距的放大比例。外观模板只表示视觉类型，不替代英雄身份识别，也不声称涵盖所有皮肤。无需给同一外观的每个阶级各做一个整格模板，但仍需要收集不同外观/朝向；先前“完全不用英雄/皮肤模板”的表述过于乐观。

## 样本和结果

- `player-example.jpg`：用户提供的原图，9个人工标注格子；也是模板来源和开发样本，9/9吻合**不是独立准确率**。格距149像素。
- `independent-battle.png`：此前真实单人战斗 `runtime/small-account/runs/20260920-190607/frame-00090.png`，432×768，未用于提取模板。全图8组英雄中4组正确、4组未知（1阶骑士、1阶冰法、两组1阶小炮）；另1空格返回未知。格距43像素。最初“4/5”仅统计5组骑士/雅典娜，且漏列了底排冰法和小炮，不代表全图结果；现已补齐全部可见英雄组，纠正分母。
- 人工标注的格子中心在 `samples.json`；本实验评估已定位格子内的阶级，不评估自动定位棋盘。
- 遮挡压力测试：把开发图三人红发组合的后排头部遮住后，当前模型会输出2阶。此局限尚未解决；连续帧能帮助短暂遮挡，但不能保证消除持续遮挡或系统性误判。不能据此自动合成。
- 4阶只有用户图中的游侠开发样本，尚无独立4阶验证，不能泛化为全英雄4阶已支持。

## 复现

依赖同项目OpenCV/NumPy。将 `.local/python-deps` 加入 `PYTHONPATH`，运行：

```powershell
python games/bilibili_hero_merge/tier_vision.py docs/evidence/tier-vision/samples.json --output runtime/tier-vision-report
```

生成带头部框、格子编号与阶级的PNG及 `results.json`。`T1`～`T4`表示候选阶级，`?`表示未确认；score为模板相似度，不是校准概率。

合作脚本可选 `--trace-tiers`，轮询已确认占用格并记录 `visual_tier_candidate`。结果仅记录，不写入跟踪器阶级，不参与合成；每次输入或不稳定观察都会清除时序累积。默认关闭，以免原型耗时影响实战。本轮未启动游戏测试。
