# Tata 子功能：电脑端自动钓鱼

适用于当前 Windows 微信里的「塔塔冒险队 → 钓鱼大赛」。打开且只保留一个游戏窗口，停在钓鱼页或已识别的鱼获页。双击仓库根目录 `Start-Fishing.cmd` 打开控制面板，点击 **开始钓鱼** 运行，再点 **停止钓鱼** 停止。面板提供运行时长设置（默认 30 分钟）、当前阶段、出杆次数、收杆点击次数和鱼获计数。

**F8**、`Stop-Fishing.cmd`、关闭控制面板也可以停止；切到其他窗口或最小化游戏也会停止。面板自动摆在游戏旁边并保持可见，开始时自动把游戏切到前台。游戏需保持可见，不要覆盖游戏窗口或手动操作鼠标。点击面板停止按钮时会离开游戏前台，视作正常停止。

依赖 Windows、Python、numpy、opencv-python。当前电脑已有依赖，无需安装手机端应用、ADB 或 FFmpeg。

```powershell
python run.py tata fishing --activate --casts 10 --seconds 600
python run.py tata fishing --observe --seconds 30
python run.py tata fishing --panel
```

程序自动定位标题为「塔塔冒险队」的唯一窗口，读取每次的实际位置、大小，归一化为 400×750 进行识别。当前配置针对已验收的窗口比例；缩放变化较大时需要重新核验。

## 行为

- 识别绿色出杆、紫色上钩、黄色区域及红色浮漂。
- 最近数帧拟合速度，补偿采集和输入延迟，必要时在两帧之间定时点击；处理轨道反弹和浮漂短暂遮挡黄区，转向或突变时不沿用旧方向。
- 自动收取普通鱼获、关闭稀有鱼展示并续杆。
- 支持「刷新个人纪录」等已知标题，并按卡片布局识别其他鱼获展示页，点击空白区域后继续运行；普通、稀有和已识别的纪录鱼获均计数。
- 只在游戏处于前台且按钮没被其他窗口遮住时点击。F8 是紧急停止键。
- 单窗口有进程锁；陌生页面等待约 1.1 秒后尝试点击游戏内空白区域，最多重试 3 次，持续约 10 秒仍未恢复则停止。窗口关闭或离开前台时停止。
- 新运行证据保存在仓库根目录的 `runtime/tata/fishing/<时间>/`，包括状态截图、点击日志和滑块采样。`--lead-ms` 默认 40 毫秒，代表额外的显示及输入补偿；不是保证准确的固定设备延迟。
- 循环等待已缩短：回到首页稳定约 0.12 秒后出杆，结果页稳定约 0.1 秒后收鱼；截图压缩/保存由后台线程完成。游戏自己的等待上钩和收鱼动画仍需等待。

## 实测与限制

2026-10-23 初次电脑端验收：完整经过出杆、上钩和 7 次预判收杆点击，结果为 113.79 kg 旗鱼。整窗采集最初测试中位约 33 毫秒，含识别的循环中位约 43 毫秒；鼠标输入约 6～19 毫秒。黄色区间可能被浮漂短暂遮挡，仍须保守保留边距。

随后连续 4 杆验收完成，普通鱼获收取、稀有鱼展示页关闭和续杆均通过，运行在出杆前按杆数上限结束。第二轮识别循环中位约 45 毫秒，截图与事件在 `runtime/fishing-desktop/20261023-194601/`。这是有限轮次的功能验收，尚非长时间稳定性或命中率统计。

修复纪录页漏识别后，实测收下遗留的纪录鱼并连续完成 5 杆，未出现陌生页面停机。首页至出杆间隔从旧版约 1.15 秒降至 0.15～0.20 秒；证据在 `runtime/fishing-desktop/20261023-200329-375292/`。同时限制黄色区域检测只读取轨道内部，避免上方收杆成功文字扩大目标区，并跳过浮漂暂停动画中的低速样本。

当前没有内存读取、进程注入或游戏数据修改。可访问性树未暴露滑块数值；进程参数未发现开放的远程调试入口。发现该游戏为带 WASM/Unity 缓存的微信渲染进程，但这不等于已经找到实时速度、位置或判定字段。当前视觉方案已可完成滑块流程，暂不依赖内存定位。

Windows 官方客户端解决了本次 MuMu 登录环境这一变量，不能保证自动化操作不会受到平台限制。此前用户已确认受限的是微信账号；详见[调查记录](../docs/FISHING-INVESTIGATION.md)。

2026-10-23 最后保留的小黄区预判、通用鱼获卡片与空白恢复版本通过 15 项离线回归。连续 5 杆及屏蔽展示页识别的恢复试验已有本地日志，未统计长期命中率。页面特效仍可能干扰浮漂识别；未知页面恢复不保证成功。整理目录时仅做离线检查，没有重新启动游戏操作。

## 验证与运行文件

```powershell
python -m unittest discover -s games/tata/fishing -p "test_*.py" -v
```

识别模板 `assets/` 与测试实际引用的截图 `testdata/` 纳入版本控制。临时截图、录屏、运动采样、日志、停止信号与本地调试脚本不提交，统一保存在仓库根目录的 `runtime/` 或 `.local/`。此前的 `runtime/fishing-desktop/` 是未迁移的历史证据目录，同样被忽略。

## 文件

- `desktop.py`：电脑端状态机、速度估计、循环与日志。
- `panel.py`：启停按钮、时长设置、状态和计数界面；后台进程退出后自动恢复开始按钮。
- `windows.py`：屏幕采集和有前台检查的鼠标输入。
- `desktop_vision.py`：电脑界面的颜色与模板识别。
- `aim.py`：滑块速度估计、小黄区时机预判与反弹处理。
- `snapshots.py`：后台保存证据截图。
- `paths.py`：仓库路径和 Tata 钓鱼运行目录。
