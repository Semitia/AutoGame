# 哔哩哔哩英雄合成小游戏

正式游戏名称为《永远的蔚蓝星球》，保留旧目录标识以兼容已有脚本。旧入口 `bilibili_hero_merge` 使用第34关固定策略；`blue_planet` 支持指定关卡与四位置战术；另有双人合作单局候选入口。

推荐双击根目录 `Start-GUI.cmd` 配置和启动，支持本地配置缓存。参见 [GUI 使用说明](../../docs/GUI.md)、[通用战术](../../docs/TACTICAL-RUNNER.md) 和 [双人合作](COOP.md)。下述阵容规则描述旧版默认策略。

## 策略

- 随机召唤一阶，同角色同阶合成，最高四阶；合成后重新读取角色。
- 比较下一次强化费 E 和召唤费 S：E < 2S 强化，E > 2S 召唤，相等优先召唤。不是累计支出。
- 海王、剑圣有空格时保留；雪姬、美人鱼保留上限各 2，多余者优先低阶合成。
- 应召唤但满格时先合成多余辅助/控制，再用输出腾位；没有允许组合时可暂时强化。
- buff 优先海王、剑圣、雪姬、美人鱼；四阶同角色选项默认中间。
- 有钱按当前策略持续消费；不主动存钱。

## 识别

RapidOCR + ONNX Runtime 本地识别名称、价格和卡片文字；OpenCV 匹配界面和格子边框。占用初筛采用 28×24 灰度区域标准差 > 22，不是英雄检测模型。

召唤识别只检查此前未占用位置；点击详情读取角色名。阶级从已确认动作推导，增量补回的未知阶级记为 0。未知单位不阻止其他单位合成或强化。

## 已知限制

随机城墙有漏检；buff 分类主要是关键词和颜色直方图；阶级缺少独立视觉校验；修复扫描仍可能耗时或误识；截图/输入延迟限制频率。通用战术可通过 GUI 或 JSON 调整，但新组合及新关卡仍需采样验证。

模板目录包括历史第 35 关素材，作为后续扩展参考；不表示当前入口支持第 35 关。
